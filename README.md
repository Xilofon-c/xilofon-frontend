# Xilofon

Cargo-arrangement platform for transport companies. Set trailer dimensions, upload a bill of lading, and stage loads against real constraints.

## Stack

React 19, Vite 7, TypeScript, React Router, Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start the Vite dev server |
| `npm run build`   | Type-check and production build |
| `npm run preview` | Preview the production build |
