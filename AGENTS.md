Solution Concept
The proposed solution is a B2B web application for cargo arrangement inside trailers. The application optimizes the placement of cargo based on box dimensions and trailer size. The application also gives loading staff a clear, visual plan for the load.
The application has two user types:
Office user – creates the Bill of Lading (BOL) and enters shipment data.
Loading user – loads the trailer according to the system's plan.
The purpose of the application is to reduce load time, reduce wasted trailer space, and reduce loading errors. The application replaces manual, paper-based load planning with an automated, visual process.
Main features:
BOL generation. The office user scans an existing BOL, or enters product data to create a new one. The system reads the trailer size and the cargo data.
Automatic load optimization. The system calculates an efficient arrangement of all boxes inside the trailer.
Barcoded BOL output. The system generates a BOL PDF with a barcode. The office user prints this document for the loading user.
3D visualization. The loading user scans the BOL barcode. The system shows the load plan in a real-time, interactive 3D view.
Box-level tracking. Each box has its own barcode. The loading user can scan a box to see its assigned position in the trailer.
Route-based load sequencing. For multi-stop routes, the system plans the unload order of the cargo. This removes the need to unload the full trailer at each stop and reload the remaining cargo.
